# AV Impacttetur 3D Control Simulator

Open `web/index.html` in a modern browser. This is the game-style build with direct manual control.

## Controls
W/S or Up/Down: pitch • A/D or Left/Right: roll • Q/E: yaw • Space: launch/boost • P: pause • R: reset.

On-screen controls provide the same functions plus continuous throttle, elevator, rudder and aileron sliders.

Camera modes: Chase, Cockpit, Orbit, Side, Front.

The simulation is reduced-order and intended for interactive engineering/software exploration, not flight certification.
